# Scrapping de Provas de Concurso

Esse é um pequeno script em python que permite que o usuário insira a banca da qual ele quer conferir as provas, após pegar todas as provas daquela banca o usuário pode filtrar por Palavras Chave de acordo com o interesse dele pela vaga, Ano Minimo (Ex: Colocar 2015 e com isso só irá buscar provas de 2015 pra frente) e Orgão. O resultado final é uma planilha excel com as provas da banca escolhida que batam com os filtros
